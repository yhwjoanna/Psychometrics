01　作業目的

作業目的與可使用工具

依課程大綱，本作業由學生個人獨立完成一份具可重現性的量化與質化分析診斷報告，檢驗下列能力：

  1. 以 AI Agent 規劃與執行資料清理：草率作答（直線作答與隨機亂填）與開放題疑似 AI 代答的偵測、反向題轉換、遺漏值處理，每一步保留人數紀錄
  2. 以獨立樣本 t 檢定與單因子 ANOVA 比較廠區、部門與年資差異，找出核心問題單位並描述差距型態
  3. 以留任意願為依變數進行多元迴歸，報告標準化迴歸係數、VIF 與殘差檢查；全公司之外，另以指定廠區重做一次並比較
  4. 以 LLM Agent 輔助開放題 OE2 的編碼，並與自己的人工編碼比較
  5. 對 AI 產出的每一項結果進行人工查核，留下紀錄

可使用工具：ChatGPT/Codex、Claude/Claude Code、Gemini/Antigravity、Excel、JASP、Python。可以混用，報告中須寫明每一個步驟使用的工具與版本或方案

03　報告架構

報告章節與必備內容

下列為建議章節。章節名稱可調整，必備內容不可缺

章節必備內容
一、資料與清理原始人數；每一個清理步驟的判定規則、門檻值與刪除人數，以及該步驟後的剩餘人數；OE1 疑似 AI 代答的判定規則與件數；反向題的判斷依據（題目對照表與題目文字是否一致）；遺漏值處理方式
二、信度各構面 Cronbach's α；α 未達 .70 的構面列出題目與總分相關，回到題目文字說明原因與處理決定
三、群組比較：核心問題單位廠區、部門與年資的比較；兩組用 Welch t 檢定並附 Cohen's d，三組以上用單因子 ANOVA 並附 η²、Levene 檢定與事後比較方法；核心問題單位的界定依據與差距型態；人數少於 5 人的群組不單獨呈現
四、驅動因子分析（一）全公司（A 部分）：構面相關矩陣；以留任意願（RET）為依變數，敬業度、主管支持、認可與回饋、組織承諾、AI 導入態度為自變數的多元迴歸；R²、標準化迴歸係數 β 與排序、VIF、殘差檢查（常態、變異數同質、離群與影響值）；相關與 β 排序不同時的說明
（二）指定廠區（B 部分）：只取指定廠區的清理後資料，重做相關、迴歸、VIF、殘差檢查與優先改善矩陣，分隔線規則與課堂相同（該廠區驅動因子 β 的平均、構面平均的平均）；與全公司比較 β 排序與象限的異同，並說明可能原因
（三）JASP 重算（B 部分）：指定廠區的迴歸在 JASP 重做一次，附錄放 JASP 截圖與對照表，做法見下方說明
五、開放題分析（B 部分）對象為指定廠區、清理後保留員工的 OE2 全部非空白回答。編碼簿（類別名稱、定義、納入與排除條件、例句）；本人人工編碼全部回答；LLM 依同一份編碼簿編碼；人工與 LLM 的一致率與 Cohen's κ，列出不一致的例子與定案理由；各類別的次數與比例；比較各類別回答者的認可與回饋（REC）構面平均，說明質化與量化結果是否一致
六、結論與管理建議結論寫在本章開頭，以人資長能直接使用的語言陳述問題單位、主要驅動因子、指定廠區與全公司的差異，以及建議行動；每一項建議對應到前面章節的數字；分析限制（模擬資料、橫斷面、相關不等於因果）
附錄對話紀錄清單、提示詞全文、程式碼、分析檢核表與分析紀錄（亦放入 ZIP）

JASP 重算指定廠區迴歸（第四章（三））

  1. 在 JASP 開啟 AI 匯出的清理後 CSV（構面分數已算好、反向題已轉換）
  2. 以 JASP 的篩選功能只保留指定廠區，確認資料列數與 AI 回報的人數相同
  3. 迴歸分析 → 線性迴歸：依變項 RET；預測變項 ENG、SUP、REC、COM、AIA 同時放入，方法為「納入」
  4. 統計量勾選估計值、信賴區間、允差值與 VIF、Durbin–Watson；圖勾選殘差 vs. 預測值、標準化殘差的 Q–Q 圖。設定方式與 Topic 08 投影片的 JASP 步驟相同
  5. 附錄放三張截圖：迴歸設定畫面、模型摘要與係數表、殘差圖；另列對照表，逐項比較 JASP 與 AI 的 n、R²、各構面 β 與 VIF。小數第三位的差異可接受；人數、β 排序或顯著與否不同時，找出原因並寫進分析紀錄
  6. 存檔為 學號_姓名_指定廠區迴歸.jasp，放入 ZIP 的 05 資料夾

格式：A4 直式，中文標楷體、英文與數字 Times New Roman，12 pt；正文 12 頁以內，附錄不計；統計報告與參考文獻依 APA 第七版，小數兩位，p 小於 .001 寫為 p < .001，每一個差異都附效果量

04　繳交項目

報告以外的五項附件

  1. 提示詞

    每一輪貼給 AI 的提示詞全文，依使用順序編號；有使用專案指示、CLAUDE.md 或 Skill 時一併附上。以 Topic07_AI分析設定範本.txt 為基礎修改者，附上修改後的版本

    檔案：.txt、.md 或 .docx

  2. 程式碼

    AI 執行的完整程式碼，整理成一份，從讀入資料到產出報告中的每一個數字都能依序重跑。以 Excel 完成的步驟附上活頁簿；指定廠區迴歸的 .jasp 檔必繳

    檔案：.py、.R、.ipynb，或貼在 Word 附錄

  3. 對話紀錄

    與 AI 的完整對話，以下列兩種形式之一提供，詳細步驟見下方說明。每一個分析階段使用一個對話即可，例如清理與比較、驅動因子、開放題各一個；所有對話依時間順序列在報告附錄的對話紀錄清單

    分享連結，或匯出的 PDF／文字檔

  4. 分析檢核表

    使用 Topic07_分析檢核表.xlsx。「預期結果」欄為課程分析程式的參考數值（A 部分）；「我的結果」欄填自己分析得到的結果；B 部分沒有預期結果，在表末自行新增列，填入指定廠區的結果，「一致？」欄記錄檢核者比對程式輸出後的判定。檢核者由另一位修課同學擔任，只負責比對「我的結果」與對話紀錄、程式輸出是否一致，不代為分析；檢核者在表頭與「檢核者」欄簽名

    檔案：學號_姓名_分析檢核表.xlsx

  5. 分析紀錄

    檢核表中的「分析紀錄」工作表。每一個需要人決定的事項寫一列：日期、步驟、決定的事項、選擇、理由、由誰提出（人或 AI）、確認者。例如隨機亂填門檻、反向題是否轉換、問題單位如何界定、迴歸是否排除離群值、開放題類別如何合併

05　對話紀錄的提供方式

分享連結與匯出紀錄

兩種形式擇一即可，同一份作業可以混用（例如網頁版用分享連結、Claude Code 用匯出）。各工具的介面名稱會隨版本更新而改變，下列步驟以功能描述為準

形式一：分享連結（ChatGPT、Claude、Gemini 網頁版）

ChatGPT、Claude 與 Gemini 網頁版都可以替單一對話建立唯讀連結，取得連結的人可以檢視該對話

  1. 開啟要繳交的那一個對話
  2. 點選對話頁面上方的「分享」（Share）
  3. 建立連結並複製。Claude 的分享視窗若預設為以電子郵件邀請特定人員，改選以連結分享（任何持有連結者可檢視）；ChatGPT 若先前已替這個對話建立過連結，選擇更新連結
  4. 將連結貼到報告附錄的對話紀錄清單，並貼在 Google Classroom 繳交時的私人留言
  5. 以瀏覽器的無痕視窗（私密瀏覽）開啟連結，確認在未登入狀態下可以看到完整對話

分享連結的限制

  • 連結內容是建立當下的對話內容。建立連結之後才送出的訊息不會出現，須重新建立或更新連結；繳交前最後一次更新連結，並再以無痕視窗確認一次
  • 上傳的檔案通常不會出現在分享頁面（Claude 的分享不包含附加檔案；ChatGPT 依方案與功能而定），部分程式執行的過程與輸出也可能無法檢視。因此程式碼仍須依第 2 項另外繳交
  • 連結須維持有效到學期成績公布。期間不刪除該對話、不取消分享；ChatGPT 可在「設定 → 資料控制 → 共用連結」檢視已建立的連結
  • 學校或企業的組織帳號可能只允許分享給同一組織的成員（例如 Claude 的 Team 與 Enterprise 方案）。無痕視窗打不開時，改用形式二

形式二：匯出紀錄（無法分享時）

適用情形：組織帳號限制分享、專案設定不允許分享、Claude Code、Codex 或 Google Antigravity 等桌面與終端工具，以及無痕視窗無法開啟分享連結時

網頁版：列印為 PDF

  1. 開啟對話，捲動到最上方，確認整段對話都已載入
  2. 展開所有摺疊的程式碼區塊與執行結果（例如「顯示程式碼」「分析過程」等按鈕）
  3. 使用瀏覽器的「列印」，目的地選「另存為 PDF」
  4. 開啟存好的 PDF，確認第一則提示詞到最後一則回覆都在，程式碼與輸出沒有被截斷；有截斷時分段列印後合併

Claude Code：/export 指令

  1. 在該次工作階段結束前，於對話中輸入 /export
  2. 依畫面選項將對話存成文字檔（亦可在指令後加檔名，例如 /export 學號_姓名_對話紀錄_01.txt）
  3. 開啟文字檔，確認提示詞、執行的指令與輸出都在檔案中

Codex：工作階段紀錄檔

  1. Codex 會把每一次工作階段自動存成紀錄檔，位置在使用者資料夾的 .codex/sessions/，依年／月／日分資料夾，檔名為 rollout-日期時間-代碼.jsonl
  2. 依分析日期找到對應的檔案，複製出來並改名，例如 學號_姓名_對話紀錄_02.jsonl，放入 ZIP
  3. .jsonl 不易直接閱讀，另將 Codex 畫面上的完整對話複製到 Word 另存為 PDF，與 .jsonl 一起繳交

其他工具

工具有匯出功能時，使用該功能匯出單一對話；沒有匯出功能時，將完整對話複製到 Word，另存為 PDF

ChatGPT 帳號資料匯出

ChatGPT 另有「設定 → 資料控制 → 匯出資料」，匯出檔包含帳號內所有對話，內容遠多於本作業所需。繳交時以單一對話列印為 PDF 為準，不繳交整個帳號的匯出檔

檔名與清單
單一檔案：學號_姓名_對話紀錄.pdf（或 .txt）
多個對話：學號_姓名_對話紀錄_01_清理與比較.pdf、學號_姓名_對話紀錄_02_驅動因子.pdf、學號_姓名_對話紀錄_03_開放題.pdf，依時間順序編號

07　AI 使用規範與學術倫理

AI 使用範圍與數字查核

  • AI 可以撰寫程式、執行分析與起草文字。報告的判斷、結論與管理建議由學生本人負責
  • 報告中每一個數字都須能回溯到程式輸出或對話紀錄中的執行結果。檢核時以 ZIP 內的程式碼重跑，結果須與報告一致
  • 依課程大綱學術倫理規範，由 AI 全文代寫且未經人工審核驗證者，該項成績以 0 分計。本作業中，捏造的數字，或無法回溯到程式輸出、未經查證的數字，所在章節以 0 分計
  • 報告附錄須有 AI 使用聲明：使用的工具、用途（程式撰寫、分析執行、文字起草、開放題編碼）與人工查核方式
  • 開放題的人工編碼由學生本人完成，再與 LLM 編碼比較
  • 檢核者只做比對與確認，不代為分析
