單元一：項目分析

item analysis

1.1 決斷值

決斷值（critical ratio，CR）檢查一題能不能區分高分者與低分者。做法是把總分排序，前 27% 為高分組、後 27% 為低分組，比較兩組在這一題的平均數，算出 t 值（Kelley, 1939）。本課程以 t 值 3.00 以上為保留標準。

1.2 校正題總相關

校正題總相關（corrected item-total correlation）是這一題與「其他題目總分」的相關，總分不包含這一題本身。本課程以 .30 以上為保留標準。出現負相關時，多半是反向題沒有反向計分，詳見測量基礎　單元四。

1.3 未達標準時的處理

  1. 先看題目內容：是否與構念定義對應、用詞是否籠統
  2. 標記為「檢查」，進入因素分析後再決定是否刪除
  3. 刪除時在企劃書 5.1 寫出題號、數值與理由

單元二：分析前的檢查

KMO and Bartlett's test

2.1 KMO 取樣適切性量數

KMO（Kaiser-Meyer-Olkin）檢查題目之間的相關是否足以抽出共同因素，數值介於 0 到 1（Kaiser, 1974）。

KMO判讀
.90 以上極佳
.80 至 .89良好
.70 至 .79中等
.60 至 .69普通，可以進行
.60 以下不適合進行因素分析，先檢查個別題目的 KMO

2.2 Bartlett 球形檢定

檢查題目之間是否彼此無關。p < .05 表示題目之間存在相關，可以進行因素分析。樣本數較大時這項檢定幾乎都會顯著，因此以 KMO 為主要依據。

2.3 樣本數

預試人數至少為題數的 5 倍，且不低於 100 人（Topic 04）。篩檢後的有效樣本也要符合這個標準。

本單元要點KMO 達 .60 以上、Bartlett 檢定顯著、有效樣本足夠，再進行因素分析。

單元三：因素數目與轉軸

number of factors and rotation

3.1 決定因素數目

方法做法提醒
特徵值大於 1保留特徵值大於 1 的因素容易保留過多因素
陡坡圖看特徵值曲線在哪裡轉為平緩轉折點不明顯時難以判斷
平行分析實際資料的特徵值高於隨機資料才保留JASP 預設方法，建議優先使用

平行分析的結果再對照理論上預設的向度數目（Hayton et al., 2004）。兩者不一致時，比較不同因素數目的結果，選擇題目歸屬清楚、能依內容命名的方案，並在企劃書說明理由。

3.2 轉軸

轉軸讓每一題盡量只落在一個因素，結果比較容易解讀。

轉軸假設例子
直交轉軸因素之間不相關varimax
斜交轉軸允許因素之間相關，並輸出因素間相關promax（JASP 預設）、oblimin

同一構念的向度通常彼此相關，本課程採用斜交轉軸（Fabrigar et al., 1999）。斜交轉軸時讀 JASP 預設輸出的負荷量表（pattern matrix）。

本單元要點以平行分析決定因素數目並對照理論；採用斜交轉軸，報告因素間相關。

單元四：負荷量與刪題

factor loadings

4.1 讀負荷量

負荷量是題目與因素的關聯強度。每一題找出絕對值最高的負荷量，就是這一題所屬的因素；再對照這一題原本預設的向度。

4.2 刪題規則

  1. 最高的負荷量低於 .40，刪除（Hinkin, 1998）
  2. 在第二個因素的負荷量也達 .32，屬於跨負荷，刪除（Costello & Osborne, 2005）
  3. 一次刪一題，從問題最明顯的題目開始，刪完重跑
  4. 刪題後每個向度至少保留 3 題，題目內容仍涵蓋構念定義

4.3 因素命名

依每個因素所包含的題目內容命名。與原本預設的向度一致時沿用原名；題目落在非預設的因素時，回頭檢查題目的寫法。

單元五：構念效度與信度

construct validity and reliability

5.1 因素結構是構念效度的一項證據

效度證據回答的問題企劃書的位置
內容題目是否涵蓋構念定義的各個面向第三章、第四章
因素結構題目是否形成預設的向度第五章 EFA
與其他構念的關係與相近構念相關但可以區別第六章

構念效度的定義與三類效度證據，見測量基礎　單元三。

5.2 信度的計算與判讀

  1. 依因素分析的結果，每個向度分別計算 α 與 ω，不計算整份量表
  2. .70 為研究初期常用的門檻
  3. 題數越多 α 越高，報告時一併寫出題數
  4. 高於 .90 時，檢查題目內容是否重複（Streiner, 2003）
  5. α 假設每一題與構念的關聯強度相同，ω 不需要這個假設，兩者都報告（McNeish, 2018）

JASP 的「if item dropped」欄顯示刪除該題後的信度，可用來確認刪題的決定；只為了提高 α 而刪題，會讓題目內容變窄。α 的題數與維度陷阱，見測量基礎　單元二。

本單元要點EFA 支持向度結構，與相近構念的區別由第六章補足；信度逐向度報告 α 與 ω。

單元六：JASP 操作步驟

JASP 0.95

6.1 開啟資料

  1. 在 Excel 完成草率作答篩檢與反向計分，另存成 CSV
  2. JASP 左上角選單 Open，選擇 CSV 檔
  3. 確認題目欄位的圖示為尺規（Scale）

6.2 探索性因素分析

  1. 上方選單 Factor → Exploratory Factor Analysis
  2. 把所有題目放入 Variables
  3. Number of Factors 維持 Parallel analysis
  4. Analysis Options 維持 Oblique：promax 與 Minimum residual
  5. Output Options 的 Display loadings above 改成 0
  6. 勾選 KMO test、Bartlett's test、Scree plot
  7. 刪題時把該題移出 Variables，結果會自動重算

6.3 信度

  1. 右上角 ＋，勾選 Reliability 模組
  2. Reliability → Unidimensional Reliability
  3. 每個向度分別放入保留下來的題目
  4. 勾選 Coefficient ω、Coefficient α
  5. Individual Item Statistics 勾選 if item dropped 與 Item-rest correlation
提醒選項名稱依 JASP 0.95 英文介面；版本不同時位置可能略有差異。
